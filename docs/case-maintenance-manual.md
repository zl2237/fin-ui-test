# UI 用例手工维护手册：元素库 → 画布 → 执行调试

> 写给谁：要在平台上**纯手工**新增、维护 UI 用例的人。全程不依赖 AI、导入脚本和命令行，只用两个东西：
> **平台网页** + **浏览器 F12**（找定位、验定位都在开发者工具里完成）。
> playwright codegen 是进阶可选（见 1.5），不再必备。
>
> 录制→解析→导入是另一条生产线（规则库 + 脚本参与），见 `docs/codegen-import.md`，本手册不涉及。

---

## 0. 三层积木（30 秒世界观）

| 积木 | 在哪维护 | 管什么 |
|---|---|---|
| **元素库** | 测试工作台 → 元素库 | "怎么找到控件"：一个控件一条记录（页面域 + Key + 定位策略）。步骤只引用它，不自己写定位 |
| **画布节点** | 测试工作台 → 用例管理 → 编辑 | "在哪个页面操作"：一个节点 = 一个页面域，节点里的动作只能用本域元素 |
| **步骤 + 数据集** | 节点配置抽屉 / 数据集页 | "做什么"：动作类型 + 元素 + 参数；会变的值一律写 `${字段}` 放数据集 |

一条用例的诞生顺序：**找定位 → 存元素 → 搭节点 → 填步骤 → 绑数据 → 跑 → 看报告调试**。

## 1. 找定位：F12 右键复制就够了

### 1.1 主路径：选中 → 抄属性 → 选策略键

1. 业务系统页面按 **F12** → 点 DevTools 左上角**箭头图标**（或 Ctrl+Shift+C）→ 点目标控件，Elements 面板即选中它。
2. **优先抄语义属性而不是整段 selector**——选中节点后直接看属性区和标签内文本：
   - 输入框有 `placeholder="请输入客户名称"` → 元素库选 **`placeholder`** 键（输入框首选，最耐改版）
   - 按钮就抄它显示的文字（「查 询」空格自动归一）→ **`button`** 键
   - 表单项旁的 label 文本（`<label>` 的 for 或包裹关系）→ **`label`** 键
3. 以上都没有（纯 class/id 定位的容器、表格单元等）→ 右键节点 → **Copy → Copy selector** 得 CSS，按 1.2 修剪后入 **`css`** 键。XPath 同理可手写；菜单没有 XPath 复制项的浏览器，用 Console `$x()` 现场构造验证。

### 1.2 修剪 Copy selector：绝对路径 → 稳定锚点

右键复制出的 selector 常是一长串绝对位置，**今天能用、页面加个 div 就断**，入库前必修剪：

```
复制的：#app > div > div:nth-child(2) > form > div:nth-child(3) > input
修剪为：form input[placeholder="请输入客户名称"]
```

- **删**：`html > body >`、`#app >` 这类祖先后缀，和 `div:nth-child(N)` 位置段——全是易碎品；
- **锚**：就近找稳定特征（id、data-*、业务语义 class、placeholder/aria 属性），写成「稳定容器 + 目标[属性]」两段式；
- **弹窗/浮层里的按钮必须把容器写进选择器**（如 `.el-dialog__wrapper:visible .el-button--primary`），否则会命中页面底下的同名按钮。

执行引擎取策略的优先级：`test_id → for → label → placeholder → button → tab → role → text → checkbox → toast → css → xpath → full_xpath`，**首个有值的键生效**。定位值支持 `${变量}`（如行内按钮按 `${bl_no}` 锁定所在行）。

### 1.3 验证唯一性（入库前必做）

Console 里：`$$("你的css")` 返回**恰好 1 个**元素才算合格（`$$(".el-dialog__wrapper:visible .el-button--primary")`）；XPath 用 `$x("//input[@id='bl_no']")`。多个就加限定、换策略。

### 1.4 整页收割：outerHTML 批量导入（比逐条手填快十倍）

元素库 → **批量导入** → 粘贴目标元素的 outerHTML（F12 选中节点 → Copy → Copy outerHTML）→
预览列表里**勾选、改 Key、补中文含义** → 入库。也认 locator JSON：`{"cust_name_input": {"placeholder": "请输入客户名称", "description": "客户名称输入框"}}`。
适合一次铺满一个新页面的输入框/按钮/勾选框。

### 1.5 进阶可选：codegen 探测器

想省手挑这步、或要给一串控件批量看定位，可以开 playwright codegen（需本地 venv）：

```bash
cd D:/CODE/PyCharm/pythonProject/fin-ui-test
.venv/Scripts/python.exe -m playwright codegen --target python "<业务系统地址>"
```

录制器右上角切 **Explore** 模式，悬停任意元素即显示定位代码（不产生操作语句，纯查定位）。它生成的语句对应元素库键：

| codegen 生成的语句 | 元素库策略键 | 说明 |
|---|---|---|
| `getByPlaceholder("请输入客户名称")` | `placeholder` | 输入框提示语，**输入框首选**，改版少 |
| `getByRole("button", { name: "查 询" })` | `button` | 按钮显示文字（空格自动归一） |
| `getByLabel("提单号")`、`getByRole("textbox", { name: "提单号" })` | `label` | 表单 label 对应的输入框 |
| `page.locator(".el-dialog__wrapper:visible .el-button--primary")` | `css` | **弹窗内按钮首选**（限定语境防同名误中） |
| `getByText("暂无数据")` | `text` | 纯文本节点 |
| `page.locator("xpath=//input[@id='bl_no']")` | `xpath` / `full_xpath` | 兜底，最脆，能不用就不用 |
| `getByTestId("xxx")` | `test_id` | 业务系统基本没埋，碰不到 |

## 2. 维护元素库

### 2.1 新增一条元素

元素库页 → **+ 新增元素**，抽屉里四个字段：

| 字段 | 怎么填 |
|---|---|
| 页面域 | 业务系统**真实路由**：浏览器地址栏 `#/` 后面的路径，如 `merchantManage/customer`。带 `/` 分层，左侧树按它分组 |
| 元素 Key | 英文小写下划线 + 用途，同域唯一，如 `cust_name_input`、`batch_add_btn` |
| 描述 | 中文人话（编排时元素下拉 hover 可见），如「客户名称输入框」 |
| 定位策略 | 「键值对」tab：下拉选策略键 + 填定位值，可多行（按 1.2 挑）；「JSON」tab 整包粘 |

右上**页面域语义**按钮：把英文域配成中文名（元素库和编排界面的左树共用显示）。

### 2.2 改版了怎么办：改策略，别删了重建

**步骤引用的是元素 id，不是 Key。** 页面改版定位失效时，在原元素上改 strategies 即可，id 不变、所有引用照常；
删了重建 = 新 id = 原来引用它的步骤全部悬空（编排里会显示裸数字 + 红字警告）。删除确认框也会提醒"引用该元素的节点将执行失败"。

### 2.3 页面域归属铁律

元素属于哪个域，就只能被那个域的节点使用——编排时选不到别域元素，保存时跨域直接 400。
一个流程要跨页面？每页一个节点，靠连线串起来。

## 3. 编排用例（画布）

### 3.1 搭骨架：节点 + 连线

用例管理 → 新建/编辑进入画布。顶栏：用例名称/描述、环境徽标（**只读**，改绑在用例列表行内）、**保存用例**（Ctrl+S）、**执行**。

1. 左侧页面域树点 **＋** → 画布出现该域节点，**首步自动生成 goto 进域页面**，不用自己写导航。
2. 工具条**连线模式**：点源节点再点目标节点，定执行顺序；双击连线删除。
3. 双击节点（或选中按 Enter）打开配置抽屉。

### 3.2 填步骤

配置抽屉 → 基础配置 → **+ 添加动作**，每个步骤卡片四件事：

1. **动作类型**：下拉选（中文名 + 标识），常用见附录速查表。
2. **定位来源**：默认「从元素库选择」——下拉只列**本节点页面域**的元素；一次性元素可切「自定义」直接写定位方式+值。
3. **动作参数**：输入内容/选项文本/按键等，支持 `${变量}`（输入框右侧按钮直接从绑定数据集插变量）。
4. **超时时间**：默认 15000ms，慢页面（远端检索类）适当调大。

卡片右侧 ↑↓ 调序、删 删除。抽屉改完点**应用配置**——注意它只写内存，**顶栏「保存用例」才落库**（有未保存改动时按钮带圆点提示）。

### 3.3 数据集

数据集页建表（列名 = 变量名），用例绑定后步骤里 `${列名}` 取值；**多行 = 整条用例逐行循环跑**。
单号类可整格写生成规则（如 `${generate_bl_no(prefix='UI')}`）。

### 3.4 断言（不写断言的绿只是"没报错"）

配置抽屉 → **断言规则** tab → + 添加断言。两类：

- **页面断言**：JSONPath 对页面事实求值。常用锚：`$.url`（节点结束时地址，SPA 跳转竞态取两态路由的公共子串）、
  `$.text`（页面文本）、`$.steps[N].result.xxx`（第 N 步的产物，**N 是全局步骤号——往前面插步会移位，插队前先把本用例的断言锚翻一遍**）。
- **DB 断言**：SQL + DB字段 + 期望值，验"真的落库了"。

### 3.5 收尾军规

- 提交/保存类按钮用 `save`（保存并确认）或 `confirm`（弹窗确认），**别裸 `click`**——确认弹窗渲染要半秒，裸点击会落空（空心绿）。
- 多选下拉（`popper_pick` 选完浮层不收）后补一步 `press Escape`，**绑定该下拉元素**，Esc 插在选完和点确定**之间**。
- 新用例优先选幂等业务动作（重复执行无害），自测要反复跑。

## 4. 运行与调试

### 4.1 执行

画布右上**执行**（先保存）。去 **执行记录** 看进度，点开报告。

### 4.2 读报告

- 左侧步骤列表：`UI · 动作名` + 耗时，红叉即失败步。
- 点任意步骤：右侧**页面截图**（失败步的终态截图是破案第一现场——"有弹窗悬空/浮层遮挡"一眼可辨）+ **页面事实 facts**（引擎实际拿到的 url / text / result / 错误）。
- 顶部**录屏回放**：环境需开录屏（系统管理 → 环境配置 → 浏览器配置 → 录屏）。
- 顶部**重跑**：整条重跑。**UI 用例没有断点续跑**——UI 步骤有不可逆副作用，按节点重放必败，入口已隐藏；改完参数就整条重跑。

### 4.3 调试三板斧

1. **看现场**：失败步截图 → 终态是弹窗悬空？浮层压住目标？还是没跳转？
2. **看 facts**：引擎拿到的 text/result 和你预期差在哪（常见：下拉显示的是选项 label 而非拼接串）。
3. **才动刀**：对症改一步，整条重跑验证。

> 想亲眼看浏览器：环境配置开**有头 + 慢放**（**只在本地环境开**，线上并发执行开了互相抢屏）。

### 4.4 高频症状速查

| 症状关键字 | 病因 | 药方 |
|---|---|---|
| `Timeout ... intercepts pointer events`（重试 15s） | 浮层没关挡住按钮，最常见：**多选下拉**选完不收起 | pick 后补 `press Escape`（绑触发器元素）；查确认框/下拉悬空 |
| 步骤全绿但业务没生效 | 确认框竞速"空心绿"：$confirm 弹窗渲染 250~500ms，紧跟的点击落空 | 提交按钮改用 `save` / `confirm(wait)`；看终态截图有无模态悬空 |
| `8s 内未见浮层选项` | 下拉没被打开，或选项文本不精确 | 查开下拉的 click 步；值必须= 选项 label 原文 |
| pick 报「input 值仍为 X」 | 选中后输入框显示的是**选项 label**，验证用精确相等 | 数据集放选项 label 单词条，别放"名称+代码"拼接串 |
| 昨天绿今天红，一批一起挂 | 多半是业务系统发版了 | 比对页面交互变化，按新交互改定位/步骤 |
| goto 后整页变登录页 | 单会话互踢：执行在跑时手工登了业务系统 | 执行期间别登业务系统；被踢等 ≥90s 再跑 |
| 节点尾 `$.url` 断言偶发挂 | SPA 跳转竞态，URL 在两态间抖 | 断言取两态路由的公共子串 |

## 5. 军规红线

| 红线 | 为什么 |
|---|---|
| 元素改策略别删了重建 | 步骤引用 id，重建即悬空 |
| 跨域元素另建节点 | 保存时跨域 400 |
| 提交类按钮用 save/confirm | 裸 click 是空心绿之王 |
| 执行在跑时别登业务系统 | 同账号单会话互踢 |
| UI 用例失败整条重跑 | 无断点续跑（不可逆副作用） |
| 含 UI 用例的方案并发 ≤2 | 浏览器槽位就 2 个 |
| 有头/慢放只开本地环境 | 线上并发互相抢屏 |

## 附：动作速查表（步骤下拉的中文名 → 干什么）

| 下拉显示（标识） | 干什么 | 关键参数 |
|---|---|---|
| 导航 `goto` | 打开路由（相对路径自动拼环境 base_url） | url |
| 点击 `click` | 点元素；「JS 直调」模式绕过可点击性校验（被遮挡/动画中） | element，可选 模式/强制 |
| 按文本点击 `click_text` | 按按钮文字点（「保 存」空格归一）；同名序号/包含匹配/无则跳过 | value |
| 输入 `fill` | 清空后整值填入 | value、element |
| 键盘输入 `type` | 逐字真敲（自定义组件无视 fill 时用） | value、element |
| 下拉选择(增强) `pick` | Element 下拉：检索→选→**自动收起**，校验选中值（单选用它） | value、element |
| 浮层选项 `popper_pick` | 点浮层里的选项（不负责开关浮层；**多选必配 press Escape**） | value |
| 按键 `press` | 按键（键名**大小写敏感**：Enter/Escape）；**绑元素更稳**（先聚焦再按，如 Escape 收浮层） | value、element |
| 勾选 `check` / 批量取消勾选 `uncheck_all` | 勾/取消复选框 | element |
| 日期时间 `date` | Element 日期选择（填值+回车） | value、element |
| 等待 `wait` | 等固定时长；**定位了元素=等元素可见** | value(ms)、element |
| 列表检索 `search` | 一体化：重置筛选→填关键字→查询→等结果行 | value、field |
| 行内按钮 `row_button` | 点表格行内按钮（可按行关键字锁定行） | value、row |
| 弹窗确认 `confirm` | 自适应点弹窗主按钮（确定/确认/继续提交…）；轮询等晚出弹窗 | 可选 轮询/无则跳过 |
| 保存并确认 `save` | 一体化：点保存→弹窗就点确定→补点→等成功 toast | 可选 期望提示 |
| 提示断言 `toast_watch` | 轮询等 toast 出现（反向模式=不得出现） | value |
| 上传 `upload` | 传文件（文件中心 ID / 绝对路径） | value、element |
| 执行JS `evaluate` | 页面里跑 JS，返回值进 facts（逃生门） | value |
| 滚动到底 `scroll_bottom` | 滚到底激活懒渲染 | — |
| 自定义动作 `custom` | 跑动作库里的 JS 模板（动作库页维护） | custom_id、args |
